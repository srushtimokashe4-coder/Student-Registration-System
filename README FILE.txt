# Student Registration System

## Project Description
A Java Swing GUI application used to register and manage student details.

## Student Details

## Programming Language
Java

## Features
1. Enter student name.
2. Enter roll number.
3. Enter email ID.
4. Enter phone number.
5. Select gender and course.
6. Register student details.
7. View registered students in a table.
8. Clear and exit options.

## How to Run
1. Open the project in EditPlus.
2. Compile StudentRegistrationSystem.java.
3. Run the program.

## Application Type
Java Swing GUI Application
